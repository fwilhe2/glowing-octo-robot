# Everything the builder image installs, one apt package per line.
#
# This replaces `apt build-dep <debian-source-package>` per package. That was convenient
# and wrong in three ways: nobody had ever seen the resulting list, it changed whenever
# sid changed, and it installed every optional dependency Debian's own build wants — so
# our configure scripts autodetected libraries we do not ship and the missing .so only
# turned up when the binary was exec'd in qemu. `test/known-missing-libs.txt` is the
# backlog that produced.
#
# So: this file is the whole contents of the builder image, and adding to it is a
# reviewable diff. The bar for a new line is that some package's build actually needs it,
# not that some Debian source package happens to list it.
#
# Lines are `#`-commented and blank-line separated; builder/Containerfile strips both.

# Deliberately absent, and the reason is always the same: our configure scripts would
# find them, link against them, and we do not ship them. Do not add one of these to fix
# a build — configure the dependency out instead, the way systemd's build.sh turns off
# every one of them by name.
#
#   libselinux-dev libselinux1-dev  no policy in the image, nothing to enforce
#   libseccomp-dev                  crun --disable-seccomp, systemd -Dseccomp=disabled
#   libaudit-dev                    no auditd, and the kernel is built without AUDIT
#   libapparmor-dev libcap-ng-dev   no userspace behind either
#   libcryptsetup-dev               systemd -Dlibcryptsetup=disabled
#   libgmp3-dev                     coreutils factor/expr bignum only
#   libreadline-dev                 util-linux fdisk line editing only
#   libfuse3-dev                    e2fsprogs fuse2fs only
#   libsqlite3-dev                  util-linux --disable-liblastlog2
#   libdb-dev                       pam_userdb, which image/files/etc/pam.d never calls
#   libgd-dev                       glibc memusagestat, a profiling tool
#   liblz4-dev                      zstd's CLI --format=lz4; the library does not need it
#   libbz2-dev libcurl4-*-dev       systemd journal remote transports, all disabled
#   libmicrohttpd-dev libgcrypt20-dev libgnutls28-dev
#   libidn2-dev libiptc-dev libpcre2-dev libglib2.0-dev libxen-dev
#   libtss2-dev libfido2-dev libp11-kit-dev libqrencode-dev libpwquality-dev
#   libarchive-dev libpolkit-gobject-1-dev libxkbcommon-dev
